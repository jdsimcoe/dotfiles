### Pragma

Custom [Iosevka](https://github.com/be5invis/Iosevka) build (family name
"Pragma"), patched with Nerd Fonts 3.3.0 glyphs. This is the Ghostty terminal
font (`font-family = "Pragma"` in `.config/ghostty/config`).

`script/setup` copies these TTFs into `~/Library/Fonts/`.
